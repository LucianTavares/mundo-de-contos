# Especificações de funcionalidades

Índice das especificações (`SPEC-NNN`). O processo está em [SDD_WORKFLOW.md](../engineering/SDD_WORKFLOW.md); use `/nova-spec` para criar ou atualizar uma especificação.

## Convenções

- Uma pasta por especificação: `docs/specs/SPEC-NNN-slug/`, com o slug em kebab-case e sem acentos.
- Arquivos: `spec.md` (sempre), `design.md`, `plan.md`, `test-plan.md`, `security-review.md` e `review.md` (conforme o fluxo).
- Números sequenciais, nunca reutilizados.
- Somente specs com status **Aprovada** ou posterior podem ser implementadas.

A ordem sugerida para o MVP está em [MVP_SCOPE.md §10](../product/MVP_SCOPE.md#10-sequência-sugerida-de-especificações-sdd).
