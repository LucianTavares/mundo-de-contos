# Architecture Decision Records

Registro das decisões de arquitetura do Mundo de Contos. Use `/novo-adr` e o [template](../templates/adr.md).

## Convenções

- Arquivo `ADR-NNNN-slug.md`, numeração sequencial de quatro dígitos, nunca reutilizada.
- Status: **Proposto → Aceito** (somente pelo responsável pelo produto), **Rejeitado**, **Substituído por ADR-NNNN** ou **Obsoleto**.
- A decisão de um ADR aceito não é editada. Para mudar, crie um novo ADR que o substitua e atualize o status do antigo.
- Os temas candidatos estão em [PRODUCT_DECISIONS.md](../product/PRODUCT_DECISIONS.md#candidatos-a-adr). Os critérios para abrir um ADR estão em [architecture.md](../../.claude/rules/architecture.md#quando-abrir-um-adr).
